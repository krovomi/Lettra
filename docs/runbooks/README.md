# Runbooks de la cellule en ligne (mode 5)

Chaque runbook dit quoi regarder, quoi faire, et comment vérifier. Ceux marqués « à éprouver » n'ont pas encore été
joués sur une vraie cellule. L'étape 5 demande de les jouer chronomètre en main.

| Runbook | État |
|---|---|
| [Mettre la cellule de recette en ligne (étape 4)](cellule-de-recette.md) | feu vert de Leub pour les étapes 1 à 3 |
| [Une création de dossier en échec](creation-de-dossier-en-echec.md) | écrit, non joué sur une vraie cellule |
| [Un cluster PostgreSQL plein](cluster-postgresql-plein.md) | à éprouver |
| [Le KMS injoignable](kms-injoignable.md) | à éprouver |
| [Rotation de la clé d'un cabinet](rotation-cle-cabinet.md) | écrit, non joué sur une vraie cellule |
| [Restaurer un dossier, puis une cellule (étape 5)](restaurer-dossier-et-cellule.md) | à éprouver |
| [Un cluster existant avant les rôles par cabinet](cluster-avant-roles-par-cabinet.md) | écrit, non joué sur une vraie cellule |
| [Le départ d'un cabinet qui a des postes reliés](depart-cabinet-postes-relies.md) | écrit, non joué sur une vraie cellule |

Les runbooks font partie de l'étape 5 du [plan du mode 5](../plan-mode-5.md) : chacun doit être joué chronomètre en main avant d'accueillir un vrai cabinet.
